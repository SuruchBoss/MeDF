# เวอร์ชันเดสก์ท็อป — พักไว้

**MeDF ไม่มีแอปเดสก์ท็อปแล้ว** โค้ด Electron และตัวติดตั้ง Windows ทั้งหมดถูกย้ายไปเก็บไว้ที่
branch [`archive/desktop`](https://github.com/SuruchBoss/MeDF/tree/archive/desktop) ไม่ได้ลบทิ้ง

```bash
git checkout archive/desktop   # โค้ดเดิมครบ build ได้เหมือนเดิม
```

## ทำไมถึงพัก

**ตัวติดตั้งที่ไม่ได้เซ็นชื่อ ขายไม่ได้** `desktop/` ไม่เคยตั้งค่า code signing
ตัวติดตั้ง NSIS ที่ออกมาจึงโดน SmartScreen ขึ้นจอเตือนว่าโปรแกรมอันตราย
ซึ่งฆ่าอัตราการติดตั้งของสินค้าที่เก็บเงิน ส่วน certificate สำหรับเซ็นมีค่าใช้จ่ายรายปี
ที่กินงบเดือนไปไม่น้อย — จ่ายก่อนมีลูกค้าคนแรกไม่คุ้ม

**PWA ให้คุณค่าเดียวกันโดยไม่ต้องเซ็น** สิ่งที่ Electron ให้คือ "ติดตั้งลงเครื่อง
ใช้ออฟไลน์ ไฟล์ไม่ออกจากเครื่อง" — ทั้งสามข้อ PWA ทำได้ครบ โดยไม่ต้องมี certificate
ไม่ต้องดูแล installer และไม่ต้องรอ build นาน

**และเมื่อไม่มีเซิร์ฟเวอร์ Electron ก็ไม่มีอะไรให้ห่อ** เชลล์เดิมมีหน้าที่หลักคือ
spawn เซิร์ฟเวอร์ Next.js เป็น child process แล้วชี้ `BrowserWindow` ไปที่มัน
พอ [`PRODUCT_DIRECTION.md`](PRODUCT_DIRECTION.md) ตัดเซิร์ฟเวอร์ออก งานนั้นก็หายไปด้วย

## ผู้ใช้ Windows ทำอย่างไรตอนนี้

เปิดเว็บแล้วกด **ติดตั้ง** จากแถบที่อยู่ของ Chrome หรือ Edge — จะได้ไอคอนบนเดสก์ท็อป
หน้าต่างของตัวเอง และใช้งานออฟไลน์ได้ เหมือนโปรแกรมที่ติดตั้งไว้
ไฟล์ยังอยู่ในเครื่องเหมือนเดิม เพราะไม่มีการอัปโหลดตั้งแต่แรก

## ถ้าจะกลับมาทำ

เงื่อนไขที่ทำให้คุ้มกลับมา: มีรายได้พอจ่าย certificate รายปี **และ** มีความต้องการ
ที่ PWA ทำไม่ได้จริง ๆ (เช่น การเข้าถึงระบบไฟล์แบบที่เบราว์เซอร์ไม่ยอมให้)
ถ้าถึงวันนั้น branch `archive/desktop` ยังรออยู่
